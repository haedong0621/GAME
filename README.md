# GAME — 2D 탑뷰 오픈월드 RPG (토이프로젝트)

*Drova*, *Core Keeper* 같은 느낌의 2D 탑뷰(위에서 내려다보는) 오픈월드 RPG를 만들어 보는 프로젝트입니다.

- **지금 단계:** 웹 브라우저에서 돌아가는 Phaser 3 프로토타입으로 "재미있는지" 확인
- **다음 단계:** 재미있으면 Godot 4로 다시 만들기 (그래서 콘텐츠는 데이터 파일로, 설계는 문서로 따로 정리해 둡니다)

## 플레이하기
- **웹에서:** GitHub Pages 주소 — `https://haedong0621.github.io/GAME/` (저장소 이름과 같이 **대문자** GAME)
  (처음 한 번은 저장소 *Settings → Pages*에서 *Branch: `main` / `(root)`*로 설정해야 열립니다)
- **조작 (컴퓨터):** `W` `A` `S` `D` (또는 `T` `F` `G` `H`, 방향키) 이동 · **마우스 커서 쪽으로 조준** · `Shift` 누르고 있으면 웅크려 걷기(조용함) · 왼쪽 클릭(또는 `J`) 공격 (박자 맞춰 연타하면 콤보) · `Space` 구르기 · 오른쪽 클릭(또는 `Tab`) 대상 고정 · `1` `2` 무기 선택
- **조작 (휴대폰, 가로 화면):** 화면 왼쪽을 누르고 끌어 이동 · 오른쪽 아래 `공격`(가까운 적 자동 조준) `구르기` `고정` `무기` 버튼
- **보스:** 시작 지점에서 오른쪽 아래(남동쪽)로 가면 *늪지 짐승*이 있습니다. 바닥에 빨간 범위가 차오르면 공격이 옵니다 — 구르기로 피하고 빈틈에 때리세요.
- **스닉:** 들판·숲에 *굶주린 들개* 무리가 있습니다. 머리 위 `?`는 의심, `!`는 발견. `Shift`로 웅크리면 소리가 작고 덜 보이며(적 시야가 바닥에 희미하게 표시됨), 풀숲에 숨으면 거의 안 보입니다. 눈치채기 전에 때리면 **기습**(큰 피해). 남서쪽 어두운 숲은 적 시야가 짧습니다.
- **저장:** 슬롯 2개 — **수동**: 거점(지금은 제작대)에 `E`로 들르면 저장 · **자동**: 보스 터 앞·지역 입구를 지나면 저장. 켜면 시작 화면에서 이어하기/불러오기/새로 시작, 게임 중엔 `Esc`(또는 오른쪽 위 *메뉴*)로 불러오기. **쓰러지면 둘 중 최근 저장으로 돌아갑니다**(그 사이 얻은 것은 사라짐).
- **제작:** 시작 지점 바로 왼쪽의 **제작대** 앞에서 `E`(휴대폰은 `열기`). 보스 재료로 *늪짐승 송곳니 검*(스킬: 독니)과 *늪짐승 가죽 갑옷*(스킬: 늪의 질김)을 만들 수 있습니다. 만들면 바로 장착되고 겉모습이 바뀝니다.
- **테스트 모드:** 주소 끝에 `?dev=1` (시작 화면 없이 바로 시작) → 왼쪽 아래 버튼으로 보스 앞 이동·보스 체력 20%·재료 받기·무적 등
- **끊김 분석:** `` ` `` 키로 입력 진단 화면, 끊기는 순간 `F8` → 직전 10초 기록 파일 저장 (Claude에게 주면 분석)
- **충돌 박스 보기:** 주소 끝에 `?debug=1` 을 붙이기

## 내 컴퓨터에서 실행하기
파일을 그냥 더블클릭하면 브라우저 보안 규칙 때문에 안 열립니다. 간단한 서버를 켜야 해요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 을 엽니다.

## 폴더 구조
```
index.html          게임 시작 페이지 (Phaser를 CDN으로 불러옴)
src/
  main.js           게임 설정과 시작
  config.js         공용 상수 (타일 크기 32px 등)
  scenes/           화면 단위 (로딩, 월드, UI)
  entities/         게임 속 물체 (플레이어, 나무, 아이템)
  systems/          공용 기능 (입력, Y-sort, 데이터, 임시 그래픽)
data/               아이템·플레이어 수치 등 콘텐츠 (JSON)
maps/               Tiled로 만든 맵 (.tmj)
assets/             그림·소리 (characters, tiles, ui, audio)
  LICENSES.md       에셋 출처·라이선스 기록
docs/
  DESIGN.md         시스템 설계 요약 (Godot 이식용 지시서)
  ASSETS.md         에셋 규격과 Gemini 이미지 생성 팁
```

## 맵 고치기
`maps/world.tmj` 는 무료 맵 에디터 [Tiled](https://www.mapeditor.org/)로 열어서 고칠 수 있습니다.
나무는 `objects` 레이어에 `type = tree` 인 점(point)으로 찍으면 됩니다.
