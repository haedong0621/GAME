# CONCEPT — 게임 기획서

> 이 문서는 "무엇을 만들고 싶은가"를 적는다. "어떻게 만들었는가"는 `DESIGN.md`에.
> 방향이 바뀌면 여기를 먼저 고친다.

## 한 줄 요약
**어둡고 거친 판타지 세계를 탐험하며, 묵직한 보스를 사냥하고, 그 재료로 장비를 만들어 더 깊은 곳으로 나아가는 2D 탑뷰 액션 RPG.**

## 레퍼런스
| 게임 | 가져올 것 |
|---|---|
| Drova | 비주얼·분위기(어둡고 거친 판타지), 세력, 회색 선택지가 있는 스토리 |
| Core Keeper | 탑뷰 시점, 보스 → 재료 → 장비 → 새 지역 해금 흐름, 생활(채집·요리·제작) |
| 몬스터 헌터 | 보스 사냥 → 보스 재료 → 보스 테마 장비 제작, 묵직한 패턴형 전투 |
| 스카이림 (모드팩) | 퀘스트 라인, 던전 탐험, 오픈월드의 "저기 가 보고 싶다" |

## 핵심 고리 (Core Loop)
```
탐험 → 보스 발견 → 준비(장비·포션) → 사냥 → 보스 재료 → 장비 제작 → 더 강한 지역/보스
   ↑                                                                          │
   └──────────────────────────────────────────────────────────────────────────┘
```
모든 콘텐츠는 이 고리에 연결된다.
- 탐험 = 보스와 재료를 찾으러 가는 것
- 던전 = 보스가 사는 곳
- 퀘스트 = 보스를 잡아 달라는 의뢰, 세력의 이해관계
- 생활 = 사냥 준비 (요리 버프, 포션, 장비 수리)

## 재미의 다섯 기둥 (우선순위 순)
1. **사냥과 장비 제작** — *핵심.* 보스마다 고유 재료, 보스 테마 장비 세트, 장비가 플레이 방식을 바꾼다.
2. **오픈월드 탐험** — 지역마다 다른 분위기·몬스터·숨겨진 장소.
3. **던전** — 입구로 들어가는 별도 공간. 함정, 퍼즐, 보스.
4. **퀘스트·세력·스토리** — 세력 선택에 따라 갈리는 이야기, 착하지만은 않은 사람들.
5. **생활** — 채집, 요리, 제작, 거점 꾸미기.

## 전투 방향: 묵직한 패턴형 (몬스터 헌터식)
- **완벽한 회피:** 공격이 닿기 직전 구르면 슬로모션 + 공격한 몬스터 휘청(?!) + 몬스터 옆에 멈춤 → 바로 공격하면 "반격!"(1.5배)
- **피격 단계:** 약한 공격은 움찔, 강한 공격은 날아가 넘어졌다 일어남(넘어진 동안 무적)
- **공격에 무게가 있다.** 휘두르기 시작하면 취소 불가: *예비 동작 → 판정 → 후딜레이*. 언제 때릴지 판단하는 게 재미.
- **회피(구르기)가 생명.** 짧은 무적 시간, 스태미나 소모. 남발하면 숨이 찬다.
- **보스는 읽는 대상.** 큰 공격 전에 반드시 예고 동작(텔레그래프). 피하고, 빈틈에 때린다.
- **장비가 리듬을 바꾼다.** 대검(느리고 강함), 한손검(균형), 단검(빠르고 약함) 등.
- 방향: 공격은 *바라보는 방향*으로 나간다(마지막 이동 방향). 마우스 조준은 추후 실험.

## "또 잡고 싶다"의 기준 (장비 제작)
1. **더 강해진다** — 당연한 기본.
2. **보스의 모습이 장비에 녹아 있다** — 그 보스 소재로 만든 장비를 입으면 플레이어 겉모습에 보스의 색·뼈·가죽·눈빛이 은근히 드러난다 (몬스터 헌터, 초기 마비노기 영웅전 느낌).
3. **보스와 관련된 특수 스킬** — 장비마다 그 보스를 닮은 스킬 (예: 늪지 짐승 송곳니 → 「독니」 독, 가죽 → 「늪의 질김」 덜 밀려남).
- 재료는 한 번 사냥으로 다 모이지 않게: 무기와 갑옷을 모두 만들려면 3~4번 사냥.

## 비주얼 방향 (결정)
- **3/4 탑뷰 2D 도트**, 8방향(그리는 건 5방향), 칼이 그림에 포함된 큼직한 공격 모션(제노니아·영웅서기식), 색감은 Drova처럼 어둡게
- 3D → 도트는 "너무 3D 같다"로 보류 (도구는 `tools/art/`에 남김)
- 배경 소품(나무·풀숲)은 입체 명암을 넣었더니 "너무 3D 느낌" → **나중에 명암 단계를 줄여(살짝 죽여) 다듬기** (지금 잡을 디테일 아님)
- 몬스터도 도트(네 발 관절 뼈대): 들개, 늪지 짐승 ✅ / 배경(타일·경계·나무·풀숲·제작대·허수아비) 도트 ✅

## 몬스터 크기 등급과 충돌 규칙
| 등급 | 예시 | 장애물(나무·바위 등) | 다른 몬스터와 부딪히면 |
|---|---|---|---|
| **소형 (잡몹)** | 들개, 구울 | 플레이어와 같은 판정. 막히면 돌아감 | 서로 밀어냄 |
| **중형 (소형 보스)** | 늪지 짐승 | 막힘 (돌진이면 그 자리에서 멈춤) | **치면서(피격) 밀어내고 돌진 계속** |
| **대형 (대형 보스)** | (추후) | **부술 수 있는 것은 부수며 통과**, 부술 수 없는 것(바위·벽)에 돌진하면 **부딪혀 비틀거림**(큰 빈틈) | **치면서(피격) 날려 버리고 돌진 계속** |

- **부술 수 있는 오브젝트:** 나무 등. 플레이어가 베서 목재를 얻는 채집과 같은 판정을 쓴다 (대형 보스 돌진에 쓰러지면 목재가 떨어짐).
- 보스가 잡몹을 치는 것은 전략이 된다: 보스를 잡몹 무리로 유인해 정리시키기.
- **결정:** 보스의 모든 공격(할퀴기·내려찍기·연속 베기·물기·도약 착지)이 바닥 범위 안의 잡몹도 때린다. **보스가 불러낸 들개도 예외 없이 맞는다** (뒤엉킨 사냥꾼은 제 무리도 벤다).
- 시기: 등급 표시는 지금 데이터에 둠, 나무 베기는 채집이 생길 때, 잡몹 충돌·돌진 피격은 M4 필드 몬스터 때, 대형 보스는 두 번째 이후 보스 때.

## 스닉(잠입) 방향 — 4가지 전부 (스카이림·Drova식)
1. **들키지 않고 지나가기** — 적에게 시야(부채꼴)와 청각이 있다. 시야 밖·소리 없이 움직이면 지나갈 수 있다.
2. **기습 공격** — 들키지 않은 적을 때리면 큰 데미지(배율). 잠든·한눈판 보스에게 첫타를 넣고 시작하는 것도 가능.
3. **환경 활용** — 풀숲에 숨으면 덜 보이고, 어두운 곳은 시야가 짧아지고, 뛰거나 구르면 소리가 크다. 웅크려 걷기는 느리지만 조용하다.
4. **훔치기·몰래 들어가기** — 마을·세력 지역에서 몰래 물건을 훔치거나 출입 금지 구역에 잠입. 들키면 세력 평판 하락·추격.
- 적의 경계 단계: **모름 → 의심(소리·흔적 확인하러 옴) → 발견(전투)** → 놓치면 다시 의심으로.
- 시기: 경계 단계 자리는 **M2 보스 AI에 미리 만들어 두고**, 실제 스닉은 **M4 필드 몬스터**에서, 훔치기·잠입은 **마을·세력이 생길 때**.

### 나중에 할 스닉 디테일 (지금은 뼈대만)
| 디테일 | 할 시점 |
|---|---|
| 나무·벽 뒤에 숨기 (시야 가림) | 던전·마을처럼 벽이 많은 곳이 생길 때 |
| 훔치기, 몰래 들어가기, 평판 | 마을·세력 단계 |
| 감지 속도·소리 크기·기력 소모 수치 조정 | 몬스터 종류가 늘어날 때 한꺼번에 |
| 횃불·빛, 바닥 재질별 발소리 | 비주얼 작업 이후 |
| 잡몹 길 찾기 개선 (나무 돌아가기) | 맵이 커질 때 |

## 세계관 방향: 어둡고 거친 판타지 (Drova식)
- 색감: 탁하고 어둡게. 이끼 낀 숲, 안개, 폐허, 늪.
- 사람들: 생존이 우선인 거친 사람들. 세력끼리 다툰다.
- 몬스터: 귀엽기보다 위협적이고 기괴하게.
- 스토리: 선악이 분명하지 않은 회색 선택지.

## 온라인 (방향만, 아직 미구현)
- 클라우드 저장 (Supabase 무료 + 구글 로그인), 브라우저 저장은 보조
- **저장 규칙 (결정):** 슬롯 2개 — **수동**(거점에서: 지금 제작대, 나중에 마을 등) · **자동**(지역 이동 지점: 보스 터 앞, 지역 입구 등) · 시작 화면에서 이어하기/불러오기/새로 시작, 게임 중 메뉴에서도 불러오기 · **쓰러지면 둘 중 최근 저장을 바로 불러옴**(그 사이 얻은 것은 잃음) · 맵에 놓인 아이템은 주운 뒤 시간이 지나면 다시 생김 (채집 단계에서 적용) · 아이템은 E로 줍는다(줍기 모션)
- **저장 단계:** ① 브라우저 저장 ✅ 구현 → ② 파일 내보내기/불러오기(백업) → ③ 클라우드
- 2~4명 협동, 무료 방식, 싱글 재미 검증 후

## 개발 마일스톤
| 단계 | 목표 | 검증 질문 | 상태 |
|---|---|---|---|
| M0 | 이동·카메라·충돌·Y-sort·데이터 읽기 | 기반이 돌아가는가? | ✅ 완료 |
| **M1** | **플레이어 기본 전투** — 묵직한 공격, 구르기, 체력·스태미나, 연습용 허수아비 | 때리고 피하는 손맛이 있는가? | ✅ 1차 완료 (콤보·무기 2종·모바일) |
| M2 | 보스 1마리 — 예고 동작이 있는 패턴 2~3개 | 보스전이 긴장감 있고 재미있는가? | 🧪 플레이 확인 중 (늪지 짐승: 할퀴기·내려찍기·돌진, 분노 단계) |

| M4 | 필드 몬스터 + 스닉 (시야·소리·경계 단계, 기습, 풀숲·어둠·웅크리기) | 몰래 다니고 기습하는 재미가 있는가? | 🧪 플레이 확인 중 (굶주린 들개 무리 3곳, 풀숲, 어두운 숲, 웅크림, 기습) |

| M7~ | 던전, 마을·세력(훔치기·잠입), 퀘스트 … | | |

**M3까지 재미있으면** 핵심 고리가 검증된 것이다. 그 뒤로 콘텐츠를 넓힌다.
