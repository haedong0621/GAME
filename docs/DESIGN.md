# DESIGN — 시스템 설계 요약 (Godot 4 이식용 지시서)

> 규칙: 시스템을 만들거나 바꿀 때마다 **해당 줄을 한 줄로** 추가·수정한다.
> 형식: `시스템 — 지금(Phaser)은 어떻게 동작하는가 → Godot에서는 무엇으로 만든다`

## 공통 규약
- **물리 시간** (`src/main.js`) — Arcade `fixedStep: false`: 물리를 화면 프레임마다 실제 경과 시간으로 계산 (고정 1/60초는 120Hz 모니터·프레임 박자 흔들림 때 "안 움직이는 프레임"이 생겨 끊겨 보였음) → Godot은 `_physics_process` 고정 틱 + **Physics Interpolation**(프로젝트 설정) 켜기로 같은 문제 해결
- **타일 크기** — 32px 고정 (`src/config.js` `TILE_SIZE`) → Godot TileSet `tile_size = 32x32`
- **좌표/정렬** — 세워진 물체의 위치 = 발밑 좌표, origin (0.5, 1) → Godot Sprite2D `offset.y = -높이/2`(또는 `centered=false`+offset)로 노드 위치를 발밑에 맞춤
- **Y-sort** — 매 프레임 `depth = 발밑 y`, 바닥 타일은 depth -1 → Godot `y_sort_enabled = true`인 부모 노드 아래에 캐릭터·나무를 둠, 바닥 TileMapLayer는 그 밖(아래)에
- **데이터** — 콘텐츠는 `data/*.json`, 시작 시 한 번 읽어 캐시 → Godot Autoload `GameData.gd`가 `FileAccess` + `JSON.parse_string`으로 읽음
- **맵** — Tiled `.tmj`, 타일셋 `world_tiles` 임베드(풀 4 + 흙길·물 경계 각 16, 물은 `collides`, 경계는 이웃 마스크로 `tools/art/pixel_world.py --remap`이 매김), 오브젝트는 Object Layer `objects`에 `type`+속성 → Godot에서는 YATI(Tiled 임포터) 애드온으로 가져오거나 TileMapLayer로 다시 그림; 오브젝트는 `type`별로 씬 인스턴스 생성

## 시스템 목록
- **부팅/로딩** (`scenes/BootScene.js`) — JSON·맵·타일셋을 미리 로드하고 임시 그래픽 생성 후 시작 화면(Title) → World+UI 씬 → Godot 메인 씬 `_ready()`에서 Autoload 초기화 후 `World.tscn` 로드
- **입력** (`systems/InputSystem.js`) — 매 프레임 "명령" `{move, aim, autoAim, attack, roll, lockToggle, switchWeapon}` 반환; 키는 `event.code`(물리 키 위치)로 읽음 — 한글 입력 상태에서도 동작, 창 이탈 시 눌린 키 해제; WASD/TFGH(보조)/방향키 이동, Shift 웅크림(`sneak`), 마우스 커서 = 조준 지점(월드 좌표, 마우스가 화면 위에 있을 때만), 왼쪽 클릭/J 공격, Space/K 구르기, 오른쪽 클릭/Tab/L 락온, E 상호작용, 1·2·3·Q 무기; 조준이 없으면 `autoAim`; 터치 조작판 결과를 합침 → Godot Input Map을 `physical_keycode`로 등록 + `Input.get_vector()` + `get_global_mouse_position()`
- **플레이어 이동** (`entities/Player.js` `updateFree`) — 목표 속도 = 방향 × `speed`, 현재 속도에서 `accel`/`decel`(px/s²)로 부드럽게 접근(8방향 꺾임 완화), 반대 방향 전환 시 `reverseAccelMultiplier`배 가속; 바라보는 반대쪽으로 움직이면 `backpedalSpeedMultiplier`까지 감속(뒷걸음질); 충돌은 발밑 박스(16×10) → Godot `CharacterBody2D`, `velocity = velocity.move_toward(target, accel * delta)` + `move_and_slide()`
- **조준·회전** (`entities/Player.js` `desiredDir`/`attackDir`/`turnTo`) — 바라보는 방향은 360도 각도(`facingAngle`); 원하는 방향 우선순위: 락온 대상 > 마우스 조준 > 이동 방향; 평소 `turnSpeedDegPerSec`로 부드럽게 회전, 공격 시작 시 원하는 방향으로 즉시 돌고, 예비 동작 중엔 `attackSteerDegPerSec`로 미세 조정; 조준 없음(키보드만·터치)이면 공격 때 `autoAimRange` 안의 가장 가까운 적 자동 조준; 조준 중 구르기는 시선 유지(백스텝) → Godot `rotation`/각도 변수 + `rotate_toward()`
- **락온(대상 고정)** (`entities/Player.js` `updateLock`) — 토글 시 `lockOnRange` 안 가장 가까운 적 고정, 죽거나 1.6배 거리 밖이면 해제; 고정 중 항상 대상을 바라봄(이동과 무관), 대상 발밑 노란 테두리 + 머리 위 화살표 → Godot 같은 규칙, 표시는 대상 자식 Sprite
- **플레이어 상태 머신** (`entities/Player.js`) — `free → windup → active → recovery → (다음 타 windup | roll | free)`; windup/active/recovery 중 입력은 예약(버퍼), recovery 시작 후 `chainAfterMs`가 지나야 다음 타·구르기로 연결; 예약이 없으면 recovery 시작 후 `moveCancelAfterMs`부터 이동 입력으로 후딜 끊기; 마지막 타 뒤 예약은 1타부터 → Godot `enum State` + `match state`
- **무기·콤보** (`entities/Player.js`, `data/weapons.json`) — 무기마다 `combo` 배열(타마다 휘두르기 각도 from/to, windup/active/recovery/chainAfter ms, 데미지, 기력, 전진 속도, 판정 원, 화면 흔들림, 히트스톱, 몸 기울기·웅크림)과 이동속도 배율; 무기 슬롯은 `data/player.json` `weaponSlots`, free 상태에서만 교체 → Godot 무기 Resource(`WeaponData.tres`, `Array[AttackMove]`), 판정은 Area2D를 active 구간에만 켬
- **히트스톱** (`entities/Player.js`) — 공격이 맞으면 `hitstopMs` 동안 플레이어 시간 정지(이동 0, 상태 타이머 멈춤, 입력은 예약) → Godot 플레이어 노드 `process_mode` 잠시 정지 또는 AnimationPlayer `speed_scale = 0`
- **무기 겉모습** (`entities/WeaponView.js`) — 손(가슴 높이)에 무기 그림, 상태별 각도: 대기=`restAngle`, windup=이전 각도→from, active=from→to(easeOutCubic), recovery=55% 유지 후 대기로; 칼끝이 위면 몸 뒤, 아래면 몸 앞 → Godot 손 Node2D + Sprite2D, AnimationPlayer rotation 트랙
- **몸 연출** (`entities/Player.js` `updatePose`) — 물리 몸체와 분리된 겉모습 이미지(`visual`)를 기울이고(lean) 웅크림/펴기(scale), windup 중 밝은 색 → Godot Sprite2D를 CharacterBody2D와 별도 노드로, 진짜 애니메이션으로 대체 예정
- **3D → 도트 캐릭터 (시험)** (`entities/Player.js` `updateHero3d`, `?hero=s|l`) — 시트 `assets/characters/hero3d_*.png/json`(행 = 동작 × 8방향, 열 = 프레임, 발밑 origin); 바라보는 각도에 가장 가까운 8방향, 걷기는 속도 비례 약 10프레임/초, 공격은 예비동작 0~40%·판정 40~65%·후딜 65~100% 구간으로 프레임 매핑(마지막 타=내려찍기), 구르기·피격·쓰러짐은 상태 진행도; 무기는 렌더에 포함(WeaponView 숨김) → Godot AnimatedSprite2D + SpriteFrames("동작_방향")
- **2D 도트 주인공 (기본)** (`entities/Player.js` `updateHeroPx`/`heroPxSheet`/`snapAttack`, 기본, 예전 캐릭터는 `?hero=old`) — 시트 `assets/characters/hero_<outfit>_<weapon>.png` + `hero_px.json`(무기 종류별 동작 행 배치, 행 = 동작 × 그린 방향 5개, 열 = 프레임; 8방향 → 그린 방향+뒤집기 표); 갑옷 `outfit` + 무기 id로 시트 선택; 칼이 그림에 포함되어 WeaponView·선 잔상 숨김; 공격 시작·예비동작 중 바라보는 방향을 45° 단위로 맞춤(판정=그림); 공격 프레임은 [예비동작 n-4장] → 잔상(판정 앞 50%) → 타격(판정 뒤 50% + 후딜 앞 40%) → 마무리 → 제자리 ; 웅크림이면 sneak/sneak_idle, 구르기·피격은 상태 진행도, 쓰러짐은 170ms마다 → Godot AnimatedSprite2D + flip_h, 갑옷×무기 SpriteFrames 또는 부위별 겹치기
- **구르기** (`entities/Player.js`, `data/player.json` `roll`) — 굴러가는 방향 = 입력 방향(없으면 바라보는 방향), 속도·시간·무적 시간(시작부터 `invincibleMs`)·기력 소모 → Godot 같은 상태 머신, 무적은 Hurtbox `monitorable = false` ; 끝나면 속도 0(미끄러짐 없음), 기본 거리 약 77px(`roll.speed` 240 × 0.32초)
- **체력·기력** (`systems/Stats.js`) — hp/stamina, 기력은 행동 후 `staminaRegenDelayMs` 지나고 `free` 상태에서만 초당 `staminaRegenPerSec` 회복, 부족하면 행동 불가 → Godot `Stats.gd` + `signal changed`
- **전투 판정** (`systems/Combat.js`) — 원(공격) vs 사각형(대상 hurtbox) 겹침 검사 → Godot Area2D 겹침 (`area_entered`)
- **몬스터** (`entities/Monster.js`, `data/monsters.json`) — 맵의 `type=monster`(속성 `monsterId`), 발밑 충돌(길 막음) + 몸 전체 hurtbox(맞는 범위), 맞으면 흰색 번쩍·흔들림, hp 0이면 `respawnMs` 후 부활(허수아비용), 머리 위 체력 바; AI는 아직 없음(`ai: none`) → Godot `Monster.tscn` = Sprite2D + StaticBody2D + Hurtbox(Area2D) + Stats
- **보스** (`entities/Boss.js`, `data/monsters.json` `ai: "boss"`) — 상태 머신 `idle → roar → chase → windup → active → recovery → chase`, 놓치면(`leashRadius`) `return`(집으로, 도착하면 체력 회복) ; 거리에 맞는 공격을 `weight`로 무작위 선택, 공격 사이 `attackCooldownMs`; 체력 비율 `phases`(예: 50% 미만 분노 — 이동·예고 속도 배율); 물리 몸체는 발밑 박스(밀리지 않음), 겉모습은 별도 이미지 → Godot `Boss.tscn` CharacterBody2D + 상태 머신, 공격 데이터는 Resource 배열
- **보스 공격 패턴** (`data/monsters.json` `attacks`) — `circle`형(앞 `offset` 거리에 반경 `radius` 원, 판정 중 짧은 전진 `lunge`), `charge`형(예고 중 `aimLockAt` 비율까지 플레이어 조준 후 방향 고정, `speed`로 돌진, 몸 원 판정, 벽에 막히면 정지); 한 공격은 플레이어에게 최대 1회 → Godot 공격별 Area2D + AnimationPlayer
- **예고 표시(텔레그래프)** (`entities/Boss.js` `drawTelegraph`) — 예고 동작 중 바닥에 빨간 범위(원은 타원, 돌진은 직사각형 경로)가 점점 진해지고 안쪽 원이 차오름, 판정 순간 진하게; 보스 몸은 웅크림+붉은 색, 빈틈(recovery)은 창백한 색 → Godot 바닥 레이어의 Polygon2D/Sprite2D + Tween
- **경계 단계** (`systems/Stealth.js` `AwarenessMeter`) — 몬스터·보스 공통 0~1 수치: 보이는 만큼(`detectPerSec × 보임 정도`) 차오르고 항상 초당 0.2씩 식음(발견 상태 제외) → 0.35 이상 의심(?), 1 발견(!); 소리를 들으면 최소 0.5(가까운 큰 소리는 즉시 1); 눈치채기 전 피격 시 `sneakAttackMultiplier` 배율(기습) → Godot 같은 수치 + 시그널
- **시야 판정** (`systems/Stealth.js` `visibility`) — `visionRange`(어두운 구역이면 × `darkVisionMultiplier`) 안 + 바라보는 방향 `visionAngleDeg` 부채꼴 안(단 `closeSenseRadius` 이내는 등 뒤도 느낌); 보임 정도 = 거리 계수(0.3~1) × 은신 배율(풀숲+웅크림 0.12, 풀숲 0.35, 웅크림 0.55); 나무 가림(시선 차단)은 아직 없음 → Godot RayCast2D로 시선 차단 추가 권장
- **소리** (`systems/Stealth.js` `NoiseBus`, `entities/Player.js` `makeNoise`) — 플레이어 행동이 반경 소리를 냄(걷기 90/0.3초마다, 웅크림 18, 구르기 140, 휘두름 110 — 칼이 지나간 뒤, 타격 170), 몬스터가 같은 프레임에 듣고 프레임 끝에 비움 → Godot 시그널 `noise_made(pos, radius)`
- **웅크리기(스닉)** (`entities/Player.js` `isSneaking`) — Shift 누르는 동안(휴대폰은 "웅크림" 토글), free 상태에서만, 이동 × `sneakSpeedMultiplier`, 몸 낮춤, 웅크린 채 움직이면 초당 `sneakStaminaPerSec` 기력 소모(회복 멈춤) → 0이면 "숨이 차다" 자동 기립(기력 15 이상 또는 Shift 뗐다 누르면 다시 가능); 웅크리는 동안 주변 적(보스 포함, 보스는 붉은색)의 시야 부채꼴을 바닥에 희미하게 표시 → Godot 같은 규칙
- **풀숲·어두운 구역** (`entities/Bush.js`, 맵 `type=bush` / `type=dark` 사각형) — 풀숲은 길을 막지 않고 밑동 주변(±15, -14~+5)에 있으면 숨음, 플레이어보다 앞에 그려 몸을 가림; 어두운 구역은 위에 어둠을 덮고 적 시야 감소 → Godot Area2D + CanvasModulate/조명
- **잡몹** (`entities/Mob.js`, `data/monsters.json` `ai: "mob"`) — 상태 `idle(어슬렁) → investigate(소리·흔적 확인, 도착 후 2초 두리번) → chase → windup → active(물어뜯기 돌진) → recovery`, `hurt`(넉백), `return`; 발견 시 `packAlertRadius` 안 무리도 발견; 시야에서 `loseSightMs` 동안 놓치면 마지막 위치 수색; 집에서 `leashRadius` 넘으면 포기; 머리 위 ?/!, 경계 막대; 처치 시 드롭, `respawnMs` 후 부활 → Godot `Mob.tscn` CharacterBody2D + 상태 머신
- **크기 등급 충돌(구현분)** — 잡몹은 플레이어와 같은 판정(나무·물·서로·플레이어와 충돌), 보스는 밀리지 않고 잡몹을 밀어냄, 중형 보스 돌진은 잡몹에게 `mobChargeDamage` 피해 + 크게 밀어내고 계속 돌진
- **플레이어 피격** (`entities/Player.js` `receiveHit`) — 구르기 무적 중이면 '회피!'(데미지 없음), 아니면 체력 감소 + 맞는 순간 `hurtFreezeMs` 멈칫 + `hurt` 상태(밀려남 `knockbackSpeed`, `hurtMs` 0.45초, 그림 5장, 콤보·예약 취소, 밀려나는 동작 후반(40%)에 누른 구르기·공격만 예약했다가 끝나자마자 실행) + `hitInvulnMs` 동안 무적(깜빡임); 결과 `hit/dodged/ignored` 반환 → Godot Hurtbox Area2D + 같은 규칙
- **피격 단계** — 공격 데이터 `knockdown: true`(늪지 짐승 몸통 내려찍기·돌진)면 **넘어짐**: 공격한 쪽을 바라본 채 뒤로 날아감(`knockdown.airMs` 동안 `launchSpeed` 감속) → 착지 흙먼지·흔들림 → 누움(`downMs`) → 일어남(`getUpMs`), 전체 무적, 일어난 뒤 0.25초 무적, 일어나는 동작 후반(50%)에 누른 구르기·공격만 예약(맞을 때·누운 동안의 늦은 입력은 버림); 아니면 기존 움찔(`hurt`) → Godot 같은 상태 머신 + 무적 플래그
- **완벽한 회피** (`Player.receiveHit` → `WorldScene.onPerfectDodge`) — 구르기 시작 후 `roll.perfectWindowMs`(0.17초) 안에 공격을 피하면: 잔상·"완벽한 회피!"·화면 번쩍·카메라 살짝 당김, 씬 시간 `perfectDodge.slowFactor`(0.3배)로 `slowRealMs`(실제 0.45초) 슬로모션, 공격한 몬스터는 `stagger`(?! 표시, `staggerMs` 동안 행동 정지); 그 자리에서 멈춤(`rollBrake` 0, 남은 구르기를 `settleMs` 0.15초로 줄여 착지, `invulnMs` 0.3초 무적); `counterWindowMs`(0.9초) 안의 첫 공격은 구르는 중에도 구르기를 끊고 나가며 "반격!" × `counterDamageMultiplier`(1.5); 그 뒤 무적 구간은 일반 "회피!" → Godot `Engine.time_scale` + 몬스터 STAGGER 상태

## 결정된 방향 (아직 미구현)
- **저장** — 클라우드 저장(Supabase 무료 플랜 + 구글 로그인) 주 사용, 브라우저 localStorage는 오프라인·비로그인 보조; 저장 데이터는 JSON 한 덩어리(플레이어·인벤토리·세계 변화) → Godot `user://` JSON 파일 + 같은 백엔드 HTTP API
- **협동** — 2~4명 협동, 무료 방식(P2P 또는 Supabase Realtime), 싱글 재미 검증 후 착수 → Godot `MultiplayerAPI`(WebSocket/WebRTC)로 재구현
- **협동 대비 원칙** — 게임 상태는 렌더링과 분리해 한곳에 모으고, 입력은 "명령"으로 변환해 처리 (지금부터 모든 기능에 적용)
- **몬스터 크기 등급** — `data/monsters.json` `sizeClass`(small/medium/large); 소형·중형 규칙 구현됨, 대형(부술 수 있는 것 부수기·벽 충돌 비틀거림)은 미구현 → Godot 같은 enum, 충돌 레이어/마스크로 구분
- **몬스터 도트 그림** (`systems/MonsterSprite.js`, `data/monsters.json` `pixelKind`) — 시트 `mon_<종류>.png` + `mon_px.json`(행 = 동작 × 5방향, 8방향 → 그린 방향+뒤집기); 보스: 대기·걷기·포효·할퀴기/내려찍기 [예고0·예고1·판정·회복]·돌진 [예고0·예고1·질주×4·멈춤]·휘청·쓰러짐, 공격 중엔 공격 방향을 봄; 들개: 대기·달리기·물기 [노림0·노림1·덮침·회복]·피격·휘청·쓰러짐 → Godot AnimatedSprite2D + flip_h
- **보스 공격 종류 확장** (`entities/Boss.js`, `monsters.json`의 `attacks[].type`) — `circle`(할퀴기·물기) · `charge`(돌진) 에 더해: `combo`(연속 베기: `hits[]` 마다 `gapMs` 동안 다음 타 범위 예고 + 플레이어 쪽으로 다시 조준 → `activeMs` 판정, 한 타씩 따로 피해야 함), `leap`(도약 덮치기: 예고 중 착지점 조준 → `aimLockAt` 이후 고정, 날아가는 동안 충돌 끔(나무·물 넘음), 그림만 포물선으로 띄움(`height`), 착지 원형 판정+넘어뜨림), `summon`(울부짖기: `summonId` 잡몹을 `count`마리, 살아 있는 수 `maxAlive` 이하로, 개별 쿨타임 `cooldownMs`) · 공격 `anim`으로 다른 동작 그림 재사용 → Godot 상태 머신에서 공격 종류별 함수, 착지점은 Marker2D, 불러내기는 signal
